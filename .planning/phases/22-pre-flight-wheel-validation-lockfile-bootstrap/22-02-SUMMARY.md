## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Tag resolution: image-id comparison instead of RepoDigests string match**
- **Found during:** Task 2 Step A (resolve dated tag for scipy-notebook)
- **Issue:** Plan's literal script compared `docker inspect --format='{{index .RepoDigests 0}}'` outputs between `:latest` and dated tag candidates. But Docker's `RepoDigests` contains a per-tag digest string that differs even when the underlying image is identical (because the digest encodes the *manifest* list which varies per tag reference). The script as-written would NEVER match.
- **Fix:** Switched to `docker inspect --format='{{.Id}}'` (image content-addressable ID) for both `:latest` and each dated tag candidate. Image-id is invariant across tag references for the same underlying image content.
- **Files modified:** None (this was an inline shell script in Task 2 Step A; corrected script committed to `/tmp/preflight-22/run-preflight.sh` for audit reproducibility but not git-committed)
- **Verification:** Resolved tag `2026-04-27` confirmed: `docker inspect quay.io/jupyter/scipy-notebook:2026-04-27` and `quay.io/jupyter/scipy-notebook:latest` return identical `Id` (`sha256:26cb95c4195c5979f4097e67ce290ff6b68e0811359e445f327b734e5cf1ddda`).
- **Committed in:** N/A (script-level correction; plan's intent preserved; output identical to what literal script *intended*)

**2. [Rule 3 - Blocking] uv installer PATH: `$HOME/.local/bin` (not `/root/.local/bin`)**
- **Found during:** Task 2 Step D (preflight_python function — running uv inside throwaway container)
- **Issue:** Plan's script set `export PATH=/root/.local/bin:$PATH` after the uv installer. But `quay.io/jupyter/scipy-notebook` runs as user `jovyan` (UID 1000), not root — `$HOME` is `/home/jovyan`, so the uv installer drops the binary at `/home/jovyan/.local/bin/uv`, not `/root/.local/bin`.
- **Fix:** Changed PATH export to `export PATH=$HOME/.local/bin:/root/.local/bin:$PATH` — covers both root-user and jovyan-user images, which is robust for any future scipy-notebook user-config change.
- **Files modified:** `/tmp/preflight-22/run-preflight.sh` (this plan's intermediate script; not committed)
- **Verification:** `uv --version` printed `uv 0.11.8 (x86_64-unknown-linux-gnu)` cleanly inside both compile and install container runs (visible in `run-3.14.log` line 2).
- **Committed in:** N/A (script-level correction)

**3. [Rule 1 - Bug] Bash `set -euo pipefail` interaction with grep -c returning 0**
- **Found during:** Task 1 verification block
- **Issue:** Verification block ran `grep -c "^pip-tools$" requirements.in && grep -c "^numpy<2.4$" …` chained with `&&`. The first grep correctly returns count `0` (which is the desired result — pip-tools is gone), but bash treats grep's exit-1-on-no-match as failure and short-circuits the rest of the chain.
- **Fix:** Re-ran each check as a separate statement with `|| true`. All 5 checks pass: pip-tools=0, numpy<2.4=1, mistune<3=1, uv pip compile=2, pip-compile=0.
- **Files modified:** None (verification command only)
- **Verification:** All 5 acceptance checks confirmed passing on second invocation.
- **Committed in:** N/A (verification-block correction)
